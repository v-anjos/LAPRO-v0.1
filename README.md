# LAPRO — Site Institucional

Site inicial da LAPRO — Liga Acadêmica de Programação, proposta vinculada ao IFTM Campus Patrocínio.

## Estrutura

- `index.html` — página principal
- `css/style.css` — estilos
- `js/main.js` — menu e recursos de acessibilidade

## Publicar no GitHub Pages

1. Crie um repositório no GitHub, por exemplo: `lapro`.
2. Envie os arquivos mantendo a estrutura de pastas.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
5. Salve.
6. Aguarde a publicação.
