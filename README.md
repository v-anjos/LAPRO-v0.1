# LAPRO — Site Institucional

Site inicial da LAPRO — Liga Acadêmica de Programação, proposta vinculada ao IFTM Campus Patrocínio.

## Estrutura

- `index.html` — página principal
- `css/style.css` — estilos
- `js/main.js` — menu e recursos de acessibilidade

## Publicar no GitHub Pages

1. Crie um repositório no GitHub, por exemplo: `lapro`.
2. Envie os arquivos mantendo a estrutura de pastas.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
5. Salve.
6. Aguarde a publicação.

O endereço será semelhante a:

`https://SEU-USUARIO.github.io/lapro/`

## Antes de publicar

No `index.html`, altere:

`SEU_EMAIL@iftm.edu.br`

para o e-mail que a coordenação definir para contato.

Também substitua os links `href="#"` das redes sociais pelos perfis oficiais da LAPRO quando eles existirem.

## Observação institucional

Enquanto a LAPRO estiver em fase de proposta, evite apresentar o site como uma página institucional oficialmente aprovada pelo IFTM. Use uma identificação como "proposta acadêmica" ou "projeto em construção" até a formalização.
